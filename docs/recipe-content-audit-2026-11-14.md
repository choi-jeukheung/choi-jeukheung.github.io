## 반영 내용

- 추가 7편: 볶음우동의 양배추 식감·돼지고기 대체, 퀘사디아의 다이어트 계기, 돼지국밥의 유튜브 참고·거품 제거·추운 날 한 끼, 불닭 덮밥의 매운맛 취향, 김치 떡만둣국의 기본 버전과 다른 맛을 반영했습니다. 부타동과 감자짜글이는 기존 조리법에 근거해 밥과 먹는 구성과 조리 포인트를 보완했으며 구체적인 새 경험은 만들지 않았습니다.

- 추가 3편: 납작고구마는 쇼츠·릴스를 보고 만든 계기와 바삭한 식감, 소금·버터의 맛을 반영했습니다. 열라면 부대찌개는 밥을 곁들이는 간단한 한 끼와 케첩의 역할을, 김치볶음우동은 매콤하고 익숙한 김치·돼지고기 조합에 대한 취향을 반영했습니다.

- 떡만둣국: 1인분·간편 조리, 익힘·간 조절 설명과 관련 만둣국 연결.
- 시오콘부 양배추 샐러드·계란밥, 어묵우동, 들깨·얼큰 만둣국, 콘치즈 불닭, 토마토 달걀볶음: 사용자가 확인한 1인분과 메뉴별 맛·만든 계기를 반영했습니다.
- 양배추 참치 샐러드, 양배추·고구마 치즈 또띠아: 기존 조리법을 바탕으로 손질, 간 조절, 붙이고 뒤집는 시점을 보완했습니다.
- 계량하지 않은 무게나 새로운 시식 경험은 만들지 않았습니다. 사진 추가와 모든 재료의 계량 확인까지 완료된 것은 아닙니다.
- 본문 수정 후 npm run build 통과. 배포는 하지 않았습니다.
