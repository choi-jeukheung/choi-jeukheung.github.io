## 태그 수정

- 공개 글 기준 태그 78개 중 글 하나짜리 51개에 noindex, follow를 적용했습니다.
- 태그 URL과 사이트 내 탐색은 유지하고, 글이 두 편 이상으로 늘면 자동으로 색인을 허용합니다.
- 태그 목록·페이지 생성에서 초안 글을 제외했습니다.
- 태그 페이지네이션에도 같은 정책을 적용하고, page/1은 기본 태그 주소를 canonical로 사용합니다.
- robots.txt에서 태그 크롤링을 막지 않습니다. noindex는 검색 결과 정리용이며 애드센스 승인 보장 또는 심사 제외 수단이 아닙니다.
